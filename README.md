# CampusBooks

Application Web monopage de revente de manuels scolaires usagés entre étudiants de la zone pilote de Longueuil, réalisée dans le cadre du **TP3 — Build & Prove (5Y5)** en HTML, CSS et JavaScript pur.

🌐 **Démo en ligne :** [https://mirkobrlek.github.io/CampusBooks_TP3_5Y5/](https://mirkobrlek.github.io/CampusBooks_TP3_5Y5/)

## Lancement en local

1. Cloner le dépôt et ouvrir le dossier dans **Visual Studio Code**.
2. Faire un clic droit sur `index.html` et sélectionner **Open with Live Server**.

> La documentation complète, les jeux de données et les rapports de tests se trouvent dans le **Wiki Azure DevOps** de l'équipe.
